# Pretty Pink Builder Lab

This repository is a clean public test bench for Pretty Pink build and CI experiments.

## Current policy

- The `main` branch stays intentionally minimal.
- Current unreleased Pretty Pink application source is **not** stored here.
- Legacy 1.1.x builder/workflow experiments are preserved on the `archive/legacy-1x-builders-2026-09-17` branch for historical reference.
- Future files added here should be disposable build/test infrastructure only.
- Do not commit signing keys, credentials, personal data, private music files, or unreleased source packages.

When a new public-testing workflow is needed, start clean from `main` rather than reviving old experiments unless there is a specific reason to inspect the archive.
